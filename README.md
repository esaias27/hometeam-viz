# HOME TEAM — Live Visuals

Audio-reactive psychedelic visualizer for iPhone / laptop. Mic + camera + multitouch, five looks, HOME TEAM logo modes. Fully offline once added to Home Screen.

**Open:** https://esaias27.github.io/hometeam-viz/

1. Open in Safari → Share → **Add to Home Screen**
2. Launch from the icon → **Tap to Start** → allow mic
3. Settings → Display & Brightness → Auto-Lock → **Never**
4. USB-C → HDMI to mirror to a TV (rotate to landscape)

Laptop keys: `1–5` looks · `←/→` next look · `L` logo · `C` camera · `P` palette · `A` autopilot · `Space` beat · `H` hide UI · `F` fullscreen

Source: `src/app.html` (built into `index.html` by `src/build.py`, which inlines the font and logo).
